OpenMASS (Open Mass Analysis Software Suite) v2025r

OpenMASS is an open-source mass photometry analysis package for landing assays
and single-particle-tracking (SPT) and was written at the Univeristy of Leicester
for analysing time series dynamics of single-molecules from mass photometry data.

Install by cloning this repo. You can run from source or the standalone .exe
Screen resolution should be 1920x1080 with 100% display scaling.

For more information, and to learn how to use the software, read the User manual
'OpenMASS User Guide.pdf' in this repo.
